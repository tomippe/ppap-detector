# PPAP Referencer

PPAPメール（暗号化ZIP添付 + 別送パスワード）を開いた時に、対応するパスワードメールを検索しやすくするChrome拡張機能です。

**OAuth認証不要！** インストールするだけで使えます。

## 機能

- 暗号化ZIPファイルが添付されたPPAPメールを自動検出
- メール本文の「Detail information」セクションから件名を抽出
- パスワードメールを検索するリンクを生成
- パスワードを手動入力して保存（セッション中キャッシュ）
- ワンクリックでパスワードをコピー

## インストール方法

1. このフォルダをダウンロード
2. Chrome で `chrome://extensions/` を開く
3. 「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. `ppap-referencer` フォルダを選択

**以上！** OAuth設定などは一切不要です。

## 使い方

1. Gmailで暗号化ZIPが添付されたメールを開く
2. PPAPメールを検出すると、右上にポップアップが表示される
3. 「パスワードメールを検索」をクリック
4. 検索結果からパスワードメールを見つける
5. パスワードをコピーして手動入力欄に貼り付け、「保存」をクリック
6. 次回から同じ件名のメールを開くとパスワードが自動表示される

## 検出条件

以下のようなメールをPPAPとして検出します：

- 本文に「パスワードは別メールで」「Please wait for a password notification email」などのキーワードを含む
- ZIPファイルが添付されている
- 「Detail information」セクションを含む

## パスワードメールの紐付け

メール本文中の以下のような情報を使って紐付けます：

```
Detail information:
Sender: xxx@example.com
Recipient: you@example.com
Subject: 〇〇の件        ← この値で検索
Message-ID: <...>
Sent time: ...
```

## プライバシー

- この拡張機能はGmailの画面上でのみ動作します
- 外部サーバーにデータを送信することは一切ありません
- OAuth認証も不要なので、Googleアカウントへのアクセス権限も取得しません
- パスワードのキャッシュはブラウザのメモリ上のみ（ページリロードで消去）

## 技術的な制限

- Gmail APIを使用しないため、パスワードの完全自動取得はできません
- パスワードメールの検索リンクを提供し、手動でパスワードを入力する半自動方式です
- GmailのDOM構造が大きく変更された場合、動作しなくなる可能性があります
